# Educo
Edinho é um bot educacional desenvolvido para auxiliar estudantes no acesso rápido e organizado a conteúdos de estudo e materiais complementares. Ele atua como um assistente virtual amigável, utilizando menus interativos para facilitar a navegação entre temas educacionais, livros e links úteis.

# 🎯 Objetivo do Projeto
Facilitar a localização e o acesso a conteúdos educacionais, contribuindo para a organização da rotina de estudos e oferecendo uma alternativa prática de consulta a materiais complementares.

## ✨Funcionalidades
• Conteúdos para estudo: acesso a materiais organizados por disciplinas.
• Disciplinas disponíveis: Lógica de Programação, SQL, Estatística e Banco de Dados.
• Categorias de conteúdo: videoaulas, exercícios e materiais complementares.
• Recursos extras: acesso a PDFs, sites úteis e ferramentas de apoio.
• Sistema de sugestões: permite o envio de sugestões e contribuições dos usuários.
• Registro de sugestões: armazenamento das mensagens recebidas em arquivo CSV.
• Navegação interativa: menus com opções para voltar e retornar ao menu principal.

## 🛠️ Linguagens, Bibliotecas e Ferramentas Utilizadas

### 🔹 Linguagem de Programação
- **Python**  
  Linguagem utilizada para o desenvolvimento do bot, escolhida por sua simplicidade, legibilidade e ampla adoção em projetos de automação e aplicações educacionais.

### 🔹 Bibliotecas
- **python-telegram-bot**  
  Biblioteca responsável pela integração com a API do Telegram, permitindo a criação de bots, manipulação de mensagens, comandos e menus interativos.

### 🔹 Ferramentas
- **Telegram**  
  Plataforma utilizada para interação com os usuários por meio do bot.
  
- **BotFather**  
  Ferramenta oficial do Telegram usada para criar, configurar e gerenciar o bot.

- **Editor de Código (VS Code / Replit)**  
  Ambiente utilizado para desenvolvimento e testes do código-fonte.

- **GitHub**  
  Utilizado para versionamento e hospedagem do código do projeto.

## 🔒 Segurança
  O token de acesso do bot é armazenado em uma variável de ambiente, evitando sua exposição direta no código-fonte. Arquivos de configuração com informações sensíveis não devem ser compartilhados publicamente.

## 📌 Finalidade acadêmica
Projeto desenvolvido individualmente para fins educacionais, como parte das atividades extensionistas do curso de Tecnologia em Ciência de Dados da Uninter.
O Educo representa uma aplicação prática de conhecimentos de programação, automação e organização de informações em uma solução voltada ao apoio educacional.

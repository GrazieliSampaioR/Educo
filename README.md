# Educo
Edinho é um bot educacional desenvolvido para auxiliar estudantes no acesso rápido e organizado a conteúdos de estudo e materiais complementares. Ele atua como um assistente virtual amigável, utilizando menus interativos para facilitar a navegação entre temas educacionais, livros e links úteis.

## Projeto desenvolvido para fins educacionais
Edinho é um bot educacional desenvolvido para auxiliar estudantes no acesso rápido e organizado a conteúdos de estudo e materiais complementares. Ele atua como um assistente virtual amigável, utilizando menus interativos para facilitar a navegação entre temas educacionais, livros e links úteis.

## 🛠️ Linguagens, Bibliotecas e Ferramentas Utilizadas

### 🔹 Linguagem de Programação
- **Python**  
  Linguagem utilizada para o desenvolvimento do bot, escolhida por sua simplicidade, legibilidade e ampla adoção em projetos de automação e aplicações educacionais.

### 🔹 Bibliotecas
- **python-telegram-bot**  
  Biblioteca responsável pela integração com a API do Telegram, permitindo a criação de bots, manipulação de mensagens, comandos e menus interativos.

### 🔹 Ferramentas
- **Telegram**  
  Plataforma utilizada para interação com os usuários por meio do bot.
  
- **BotFather**  
  Ferramenta oficial do Telegram usada para criar, configurar e gerenciar o bot.

- **Editor de Código (VS Code / Replit)**  
  Ambiente utilizado para desenvolvimento e testes do código-fonte.

- **GitHub**  
  Utilizado para versionamento e hospedagem do código do projeto.
